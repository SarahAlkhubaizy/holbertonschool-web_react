# TypeScript

Holberton School project covering the basics of TypeScript: interfaces, classes, functions, DOM manipulation, generics, namespaces, declaration merging, ambient namespaces and nominal typing.

## Requirements

- Editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
- All files end with a new line
- The TypeScript compiler must not show any warning or error
- Tests are run with `jest`

## Tasks

| Task | Description |
| ---- | ----------- |
| 0 | Creating an interface for a student |
| 1 | Let's build a Teacher interface |
| 2 | Extending the Teacher class |
| 3 | Printing teachers |
| 4 | Writing a class |
| 5 | Advanced types Part 1 |
| 6 | Creating functions specific to employees |
| 7 | String literal types |
| 8 | Ambient Namespaces |
| 9 | Namespace & Declaration merging |
| 10 | Brand convention & Nominal typing |

## Usage (per task)

```bash
cd task_0
npm install
npm run build
npm run start-dev
```
